# Offline documentary recordings

Captured/curated on 2026-10-23 from official documentation. These are bounded documentary snapshots, not captures of live authenticated API requests. The OpenAPI file is a reduced authored projection of documented fields, not the publisher's complete schema. Sample numbers are published response examples; no current-price claim is made. Fixture parameter defaults are pinned documented example inputs for deterministic demos, not promises about live service defaults.

Sources: https://docs.coingecko.com/demo/reference/coins-id-market-chart-range and https://frankfurter.dev/ and https://api.frankfurter.dev/v2/openapi.json (Frankfurter MIT project). Demo endpoint verification always stays false. Tests mock HTTP and LLM boundaries; no live credentials are needed. Demo event logs are recordings of actual offline pipeline executions with stable timestamps, not invented worker activity.
